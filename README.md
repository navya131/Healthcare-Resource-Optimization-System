# 🩺 Smart Healthcare Analytics Platform

## 📌 Overview

Smart Healthcare Analytics Platform is an AI-powered healthcare management system designed to assist patients, doctors, and administrators through intelligent healthcare analytics, resource management, and predictive insights.

The platform provides role-based access control, healthcare monitoring, patient management, and AI-driven decision support to improve healthcare operations and user experience.

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/Smart-Healthcare-Analytics-Platform.git
```

### 2. Navigate to Project Folder

```bash
cd Smart-Healthcare-Analytics-Platform
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Application

```bash
streamlit run app.py
```
